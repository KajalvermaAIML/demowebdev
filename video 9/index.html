Understanding ID and Classes in HTML

1. ID Selector (Unique)

An id must be unique within a single HTML page. It is targeted in CSS with the # symbol.

2. Class Selector (Reusable)

A class can be reused on multiple HTML elements across the page. It is targeted in CSS with the . symbol.

Class: .badge-success Class: .badge-warning

Key Difference to Remember:

Use ID when targeting a single, unique element (like #navbar or #submit-btn). Use Class when styling multiple elements that share the same visual structure (like .btn or .card).
